# 專案規格書：AlexCode - 多關鍵字代碼檢視器

## 1. 專案概觀 (Overview)
AlexCode 是一個輕量化、高效能的文字編輯器，專為 C/C++ 與 Python 開發者設計。它參考了 Notepad++ 的核心使用體驗，並整合了強大的「多關鍵字過濾」功能，旨在提升大型原始碼與日誌檔的閱讀與分析效率。

## 2. 核心目標 (Goals)
*   **極致效能**：即使在處理萬行以上的程式碼檔案時，也能維持流暢的滾動與即時語法亮色。
*   **精準過濾**：提供優於傳統搜尋的「多關鍵字交集/聯集過濾」，快速定位關鍵邏輯。
*   **簡潔易用**：介面佈局直覺，無需複雜學習成本即可上手。

## 3. 功能清單 (Features)
### 3.1 核心專屬功能
*   **多關鍵字過濾輸入**：頂部過濾欄，支援以直線 `|` 分隔的多個搜尋關鍵字 (例如：`error | func(a, b) | timeout`)。
*   **過濾邏輯切換 [AND / OR]**：
    *   **AND**：僅顯示同時包含所有關鍵字的行。
    *   **OR**：顯示包含任一關鍵字的行。
*   **結果同步面板 (Split View)**：底部顯示過濾結果列表，雙擊結果可即時跳轉至主編輯區對應行號。

### 3.2 基礎 Notepad++ 核心功能
*   **多頁籤管理 (Tabbed UI)**：支援同時開啟多個檔案進行切換。
*   **語法亮色 (Syntax Highlighting)**：支援 C, C++, Python 語法高亮。
*   **基礎編輯操作**：開檔、存檔、復原/重做 (Undo/Redo)、剪下/複製/貼上。
*   **視圖控制**：支援 `Ctrl + 滑鼠滾輪` 縮放字體、自動換行 (Word Wrap) 切換。
*   **基礎尋找 (Find)**：保留基本的單一字串搜尋功能 (Ctrl + F)。

## 4. 技術選型 (Tech Stack)
*   **開發語言**：C++ (C++17 或更高版本)
*   **UI 框架**：Qt 6
*   **核心組件**：`QMainWindow`, `QPlainTextEdit` (自定義行號區), `QSyntaxHighlighter`, `QDockWidget` (結果面板)。
*   **建置系統**：CMake

## 5. 使用者介面設計 (UI Design)
1.  **頂部 (Top)**：選單列 (Menu Bar) 與 多頁籤列 (Tab Bar)。
2.  **中間 (Center)**：程式碼編輯區，包含左側行號區。
3.  **過濾欄 (Filter Bar)**：位於選單列下方，包含關鍵字 QLineEdit、邏輯 QToolButton、與 Filter 按鈕。
4.  **底部 (Bottom)**：過濾結果 QListWidget，採用垂直列表佈局 (每行結果為獨立項目)。

## 6. 測試與驗證 (Verification)
*   **單元測試**：驗證 AND/OR 過濾邏輯之正確性。
*   **效能測試**：測試在 100,000 行檔案下的搜尋與過濾反應時間（目標 < 500ms）。
*   **介面測試**：確保雙擊跳轉功能定位精準。
